# Volker Laux

Academic website: https://volkerlaux.github.io/

Randal B. McDonald Chair in Accounting, Shulkin Department of Accounting, McCombs School of Business, The University of Texas at Austin.

## Updating the website

Edit profile details and papers in `content.json`, then run `python3 build.py` to regenerate `index.html` and `analytics.js`. The site uses ordinary HTML, CSS, and JavaScript and is published from the `main` branch by GitHub Pages.

Styling is in `styles.css`. Local previews do not send visits to Google Analytics.

Typography uses [IBM Plex Sans](https://github.com/IBM/plex), served through Google Fonts with regular, medium, semibold, and italic styles. System sans-serif fonts provide a fallback.
